# Coin Toss Analysis

## Overview

This project uses python to simulate repeated coin tosses and investigate how simulated probabilities behave as the number of tosses increases. 

The project builds on a basic probability simulation and develops it into a small statistical analysis.

## Question

Does the simulated probability of getting heads become closer to the theoretical probability of 0.5 as the number of tosses increases?

## Project Goals

Simulate coin tosses using Python.

Record the outcomes.

Calculate the proportion of heads.

Repeat the experiment with increasing numbers of tosses.

Compare simulated results with the theoretical probability.

Visualize the results.
